\section*{Project Overview}
This project investigates low-latency, privacy-preserving American Sign Language (ASL) recognition using coordinate trajectory tracking from monocular webcam feeds. Rather than relying on computationally heavy 3D Convolutional Neural Networks (3D-CNNs) operating directly on high-dimensional raw RGB video frames, the proposed architecture decouples geometric feature extraction from temporal sequence modeling. We extract 21 3D hand keypoints per frame via Google MediaPipe Hands \cite{lugaresi2019mediapipe, zhang2020mediapipe}, normalize coordinates relative to the wrist and metacarpophalangeal (MCP) joints to achieve scale and position invariance, and pass the resulting temporal sequences into temporal classifiers to identify dynamic word-level signs in real time.

\section*{Current Progress}
During the past week, we completed data ingestion and subset isolation, finalized spatial normalization, engineered kinematic trajectory features, built the PyTorch dataset pipeline, and established machine learning baseline benchmarks.

\subsection*{Data Collection and Dataset Sources}
To train and benchmark our system, we acquired and processed data from two primary complementary sources:
\begin{enumerate}
    \item \textbf{World-Level American Sign Language (WLASL) Dataset \cite{li2020word}:}
    \begin{itemize}
        \item \textbf{Origin \& Acquisition:} We obtained the official dataset annotations (\texttt{WLASL\_v0.3.json}) from the WLASL project repository \cite{li2020word, wlasl_github}. The underlying video instances indexed by WLASL originate from online educational sign dictionaries and public video-sharing platforms, including public YouTube ASL video demonstrations \cite{youtube_asl}, Signing Savvy \cite{signingsavvy}, ASL Pro \cite{aslpro}, and Handspeak \cite{handspeak}.
        \item \textbf{Subset Filtering:} We designed an automated data ingestion and filtering script (\texttt{src/data\_ingestion.py}) to isolate a 30-word dynamic target vocabulary covering frequent greetings, verbs, emergency words, nouns, and adjectives. From the master corpus, we extracted \textbf{547 validated instances} partitioned into standardized splits: \textbf{383 training instances}, \textbf{94 validation instances}, and \textbf{70 test instances}.
        \item \textbf{Annotations Extracted:} For each clip, metadata includes instance IDs, video source URLs, frame boundary intervals (\texttt{frame\_start}, \texttt{frame\_end}), native frame rates (30 FPS), and signer bounding box coordinates.
    \end{itemize}

    \item \textbf{Deterministic Kinematic Benchmark Dataset (Synthetic Hand Engine):}
    \begin{itemize}
        \item \textbf{Origin \& Acquisition:} To ensure reliable local profiling, unit testing, and controlled baseline benchmarking without dependency on external video link stability, we built a synthetic hand rendering engine (\texttt{generate\_benchmark\_dataset} in \texttt{src/data\_ingestion.py}).
        \item \textbf{Characteristics:} The generator produces 150 calibrated video clips (640$\times$480, 30 FPS, 18--65 frames per clip) executing realistic 5-finger articulation, joint curl dynamics, and smooth spatial hand trajectories for all 30 vocabulary terms.
    \end{itemize}

    \item \textbf{Real-Time Keypoint Extraction Stream:}
    \begin{itemize}
        \item Extracted 21 3D joint landmarks $(x, y, z)$ per frame ($63$ values per frame) using Google MediaPipe HandLandmarker Tasks API. Missing or occluded detections are filled using linear boundary interpolation. Monocular CPU profiling demonstrated an inference throughput of \textbf{43.7 FPS} ($22.86$\,ms per frame), safely exceeding the 30 FPS real-time webcam requirement.
    \end{itemize}
\end{enumerate}

\subsection*{Spatial Normalization and Geometric Invariance}
To ensure the recognition pipeline remains robust against user distance and camera position, we implemented two-stage geometric normalization:
\begin{itemize}
    \item \textbf{Wrist Translation Centering:} Landmark coordinates are centered relative to the wrist (Landmark 0):
    \[
        P'_i = P_i - P_{\text{wrist}} \quad \forall i \in \{0, \dots, 20\}
    \]
    \item \textbf{MCP Distance Scaling:} Hand scale is normalized by the Euclidean distance between the wrist and the middle-finger metacarpophalangeal (MCP) joint (Landmark 9):
    \[
        d_{\text{scale}} = \| P_{\text{mcp}} - P_{\text{wrist}} \|_2, \quad P''_i = \frac{P'_i}{d_{\text{scale}} + \epsilon}
    \]
\end{itemize}
Unit tests confirmed scale and translation invariance with maximum numerical deviation $\Delta_{\max} < 10^{-7}$ under arbitrary affine shifts.

\subsection*{PyTorch Dataset and DataLoader Pipeline}
We implemented \texttt{ASLKeypointDataset} and \texttt{create\_dataloaders} in \texttt{src/dataset.py}:
\begin{itemize}
    \item Trajectories of variable length (15--75 frames) are resampled to a uniform temporal window of $T = 30$ frames (1.0 second at 30 FPS) via 1D spline interpolation, producing tensor batches of dimension $(\text{batch\_size}, 30, 63)$.
    \item Training batches incorporate kinematic coordinate augmentations: Gaussian jittering ($\sigma = 0.01$), random spatial scaling ($s \in [0.92, 1.08]$), and in-plane rotational perturbations ($\theta \in [-12^\circ, +12^\circ]$).
\end{itemize}

\subsection*{Kinematic Feature Engineering and Baseline Models}
To establish an empirical baseline before training deep recurrent networks, we engineered 714 aggregated summary features per 30-frame sequence (spatial coordinate statistics, net trajectory displacement $P_{T-1} - P_0$, first-order velocity dynamics $\Delta P / \Delta t$, second-order acceleration $\Delta^2 P / \Delta t^2$, and cumulative joint path lengths).

We trained and evaluated tuned non-deep-learning classifiers across the 30-word vocabulary:
\begin{itemize}
    \item \textbf{Random Forest Classifier \cite{breiman2001random}:} 150 estimators, balanced class weights.
    \item \textbf{Support Vector Classifier (SVC) \cite{cortes1995support}:} Radial Basis Function (RBF) kernel ($C = 3.0$) with standard feature scaling.
\end{itemize}

\section*{Challenges and Issues}
\begin{itemize}
    \item \textbf{Disambiguating Geometric Minimal Pairs:} Words with near-identical gross arm trajectories (e.g., \textit{hello} vs. \textit{goodbye}, or \textit{food} vs. \textit{eat}) are challenging for static feature aggregations, limiting Top-1 accuracy to 53.33\%. However, the target sign consistently appears within the Top-5 predictions (86.67\%). This confirms the necessity of deep sequential architectures (BiGRU and 1D-TCN) to learn subtle phase-dependent temporal transitions.
    \item \textbf{Numerical Differentiation Noise:} Calculating velocity ($\Delta P / \Delta t$) and acceleration ($\Delta^2 P / \Delta t^2$) directly on raw discrete coordinates amplified high-frequency sensor noise. Applying temporal spline smoothing prior to differentiation resolved these derivative spikes.
    \item \textbf{Web Video Link Degradation in Public Datasets:} In large-scale video corpora like WLASL, external video URLs may periodically encounter hosting changes. We mitigated this by caching isolated subset annotations locally and integrating our synthetic benchmark engine for deterministic testing.
\end{itemize}

\section*{Next Steps}
Our primary milestones for the upcoming week include:
\begin{itemize}
    \item \textbf{Bidirectional GRU (BiGRU) Implementation:} Build and train a 2-layer BiGRU with hidden dimension $H = 128$, dropout regularization ($p = 0.3$), and temporal attention pooling operating directly over sequence tensors of shape $(\text{batch\_size}, 30, 63)$.
    \item \textbf{1D Temporal Convolutional Network (1D-TCN):} Implement a dilated 1D-TCN backbone with dilation factors $d \in \{1, 2, 4, 8\}$ and residual connections for low-latency multi-scale temporal modeling.
    \item \textbf{Dual-Hand Expansion (126-D):} Expand input tensor dimensions to 126 features ($42$ keypoints $\times$ 3 coordinates) with zero-padding for single-hand signs, enabling recognition of two-handed signs (e.g., \textit{book}, \textit{house}, \textit{more}).
    \item \textbf{Comparative Ablation Study:} Benchmark Random Forest vs. BiGRU vs. 1D-TCN across Top-1 accuracy, Top-5 accuracy, parameter count, and inference latency (ms).
\end{itemize}

\section*{Questions or Feedback Needed}
\begin{itemize}
    \item \textbf{Two-Hand vs. Single-Hand Representation Strategy:} We are expanding to a 126-dimensional representation ($42 \times 3$ features) zero-padded when only one hand is active. We would appreciate feedback on whether zero-padding is preferred, or whether providing an explicit binary hand-presence mask input to the recurrent network would be beneficial.
    \item \textbf{Evaluation Benchmarking Focus:} In addition to standard Top-1 and Top-5 accuracy, we are prioritizing Macro-Averaged F1-score to ensure class-imbalance invariance. We welcome your recommendations on whether user-study latency percentiles ($p_{95}$ latency) should also be reported.
\end{itemize}
